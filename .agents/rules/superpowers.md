# Superpowers Workflow

This project is equipped with the Superpowers engineering methodology.

When developing in this project:
1. **Never guess or rush**: Always invoke the appropriate skill before taking action.
2. **Feature Development**: Follow the workflow: `brainstorming` -> `writing-plans` -> `executing-plans` (or `subagent-driven-development`) -> `verification-before-completion`.
3. **Coding & Bug Fixing**: Follow `test-driven-development` (RED-GREEN-REFACTOR) and `systematic-debugging` (root-cause tracing before editing code).
4. **Skills Location**: Custom skills are located in [.agents/skills](file:///home/tyoot/1agent%20work/1/.agents/skills) and [.agents/plugins/superpowers/skills](file:///home/tyoot/1agent%20work/1/.agents/plugins/superpowers/skills).
